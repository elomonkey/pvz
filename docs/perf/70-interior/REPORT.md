# Интерьер по референсу — issue #70

Сравнение свежего main `6f227ba` и изменений `sol/70-interior-reference`. Один Chromium, viewport 1280×900, deviceScaleFactor 1, seed 73129, 2 секунды прогрева и 5 секунд RAF-замера. До/после использованы одинаковые клиенты и набор декора. Угол камеры сохранён; кадр немного расширен и сдвинут, чтобы вместить увеличенный склад.

| Сцена | Draw calls до → после | Треугольники до → после | Текстуры | Программы | avg/p95/max frame time до → после, мс |
|---|---:|---:|---:|---:|---|
| 2 клиента | 122 → 126 | 60 615 → 63 395 | 16 → 14 | 9 → 9 | 103,74 / 116,70 / 116,80 → 79,42 / 83,40 / 83,40 |
| 4 клиента + всё оформление | 173 → 177 | 83 430 → 86 210 | 19 → 17 | 9 → 9 | 119,44 / 133,40 / 150,00 → 90,17 / 100,00 / 100,10 |

`npm run perf -- --label interior-after --check-budget` проходит. Лимиты 150 calls для 2 клиентов и 180 calls / 150k triangles для 4 клиентов соблюдены. Shadow maps выключены, стоимость refresh = 0. Два прежних PointLight в подвесах убраны; светящиеся поверхности и локальные мягкие пятна работают без shadow maps и постобработки.

Замер сделан на **SwiftShader** (software renderer), поэтому абсолютные frame time не описывают FPS реального телефона. Это локальное сравнение при одинаковой нагрузке; draw calls, triangles, textures и programs — проверяемый бюджет. Запас по draw calls для будущего магазинного декора небольшой: 3 calls при текущем полном наборе. Новые товары потребуют собственного бюджета/батчинга.

Сырые отчёты: [до](before.json), [после](after.json). В after.json revision указывает на исходный HEAD, поскольку замер выполнен до коммита изменений; он относится к рабочему diff по issue #70.
